# app_data/ffmpeg-local

Binarios portables de **FFmpeg** (`ffmpeg.exe`, `ffprobe.exe`, `ffplay.exe`) para procesar audio/vídeo sin instalación del sistema. Referenciada por `Llama_Server_Manager.py`.

> Los archivos reales de esta carpeta **no se incluyen en el repositorio** (binarios, modelos o datos): se crean o se colocan al instalar / ejecutar Llama Server Manager.
