# app_data/edgewv2sdk

Runtime del **SDK de WebView2 (Microsoft Edge)** que usa `tools/web_viewer.py` para mostrar vistas web embebidas en la aplicación. La estructura interna se genera automáticamente al primer uso.

> Los archivos reales de esta carpeta **no se incluyen en el repositorio** (binarios, modelos o datos): se crean o se colocan al instalar / ejecutar Llama Server Manager.
