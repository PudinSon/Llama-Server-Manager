# app_data/laya

Modelo ONNX del router semántico **Laya** (encoder mmBERT multimodal, float16): `model.onnx`, `onnx_config.json`, `rl_agent_config.json` y la carpeta `tokenizer/`. Gestionado por `tools/laya_downloader.py` y usado por `tools/laya_onnx_router.py`.

> Los archivos reales de esta carpeta **no se incluyen en el repositorio** (binarios, modelos o datos): se crean o se colocan al instalar / ejecutar Llama Server Manager.
