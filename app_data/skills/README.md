# app_data/skills

Skills del agente: una carpeta por skill, cada una con su `SKILL.md` (nombre, descripción e instrucciones). Se cargan como capacidades reutilizables del flujo agéntico.

> Los archivos reales de esta carpeta **no se incluyen en el repositorio** (binarios, modelos o datos): se crean o se colocan al instalar / ejecutar Llama Server Manager.
