# app_data/agency-agents

Catálogo de agentes reutilizables para el modo agencia: cada subcarpeta agrupa definiciones de agentes en archivos `.md` (prompt de sistema, capacidades y reglas) organizadas por área de especialidad. El catálogo se expone a través de `tools/agency_catalog.py`.

> Los archivos reales de esta carpeta **no se incluyen en el repositorio** (binarios, modelos o datos): se crean o se colocan al instalar / ejecutar Llama Server Manager.
