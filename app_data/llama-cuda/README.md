# app_data/llama-cuda

Binarios de **llama.cpp (build CUDA)** con soporte GPU: DLLs de NVIDIA (`cudart64_12.dll`, `cublas64_12.dll`, `cublasLt64_12.dll`) y las `ggml-*.dll` con backend CUDA. Alternativa acelerada a `llama-cpp/`.

> Los archivos reales de esta carpeta **no se incluyen en el repositorio** (binarios, modelos o datos): se crean o se colocan al instalar / ejecutar Llama Server Manager.
