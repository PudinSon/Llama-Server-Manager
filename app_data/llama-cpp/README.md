# app_data/llama-cpp

Binarios de **llama.cpp (build CPU)**: `llama-server.exe`, `llama-cli.exe`, utilidades y las DLLs `ggml-*.dll` (incluidas las variantes optimizadas por microarquitectura: alderlake, haswell, skylakex, zen4, etc.). El manager lanza `llama-server.exe` desde aquí.

> Los archivos reales de esta carpeta **no se incluyen en el repositorio** (binarios, modelos o datos): se crean o se colocan al instalar / ejecutar Llama Server Manager.
